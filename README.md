# The Linux Command Line – Deutsche Übersetzung

> „Freies Wissen verdient es, von möglichst vielen Menschen verstanden zu werden.“

## Worum geht es?

*The Linux Command Line* von **William Shotts** gehört zu den bekanntesten und besten Büchern über die Linux-Kommandozeile. Das Buch steht unter einer freien Lizenz und wurde bereits in zahlreiche Sprachen übersetzt.

Nur eine deutsche Übersetzung fehlte bisher.

Das möchten wir ändern.

## Die Idee

Im Rahmen meines Studiums an der Fachhochschule muss ich *The Linux Command Line* lesen. Das englische Original ist hervorragend geschrieben und gut verständlich. Trotzdem stellte sich schnell die Frage:

**Warum gibt es dieses Buch eigentlich nicht auf Deutsch?**

Aus dieser einfachen Frage entstand ein Projekt.

Der **Hackerspace Odenwilusenz** hat sich zum Ziel gesetzt, eine hochwertige deutsche Übersetzung zu erstellen und sie der Open-Source-Community zur Verfügung zu stellen.

Denn Open Source bedeutet nicht nur, Quellcode frei zugänglich zu machen. Open Source bedeutet auch, Wissen zugänglich zu machen.

## Arbeitsweise

Die komplette Übersetzung wird in **Markdown** geschrieben und mit der Open-Source-Software **Zettlr** bearbeitet.

Dadurch bleibt das gesamte Projekt:

- versionsverwaltet mit Git
- leicht lesbar
- einfach erweiterbar
- langfristig wartbar

Aus den Markdown-Dateien können anschließend verschiedene Ausgabeformate wie PDF, HTML oder EPUB erzeugt werden.

## Mitmachen

Auch wenn dieses Projekt derzeit hauptsächlich von einer Person umgesetzt wird, freuen wir uns über jede Unterstützung.

Ob Rechtschreibfehler, Formulierungen, fachliche Hinweise oder komplette Kapitel – jede Verbesserung hilft dabei, eine möglichst hochwertige deutsche Ausgabe dieses großartigen Buches zu erstellen.

## Danksagung

Ein besonderer Dank gilt **William Shotts**, der dieses hervorragende Buch unter einer freien Lizenz veröffentlicht und damit dieses Übersetzungsprojekt überhaupt erst möglich gemacht hat.
